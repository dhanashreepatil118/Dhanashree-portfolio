# Dhanashree Patil Portfolio

Pure HTML + CSS + JavaScript portfolio website.

## Files

- index.html
- style.css
- script.js
- assets/

## Run

Simply double-click `index.html` or open it in a browser.

## Customize

1. Replace the hero image URL in `index.html`.
2. Replace `dhanashree@example.com` with your real email.
3. Add your real LinkedIn/GitHub/Instagram/YouTube links.
4. Put your resume inside `assets/` and name it:
   `Dhanashree-Patil-Resume.pdf`
5. Update projects, certificates and skills as required.

No npm, Node.js or framework is required.
